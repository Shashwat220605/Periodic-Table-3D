# Interaction notes

The 3D periodic-table interface contains several interactive controls, so changes should be checked for both visual placement and interaction flow.

## UI checklist

- Verify controls do not overlap at the supported viewport sizes.
- Confirm opening a panel does not obscure the control that closes it.
- Check that mouse and keyboard interactions remain usable after layout changes.
- Test transitions from a clean page load as well as after another panel has been opened.
- Include screenshots when a pull request changes the visible layout.
